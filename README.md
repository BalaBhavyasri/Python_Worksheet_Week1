## Programs Description

### Q1 – Temperature Conversion Function

- Converts temperature from Celsius to Fahrenheit.
- Uses a Python function and arithmetic operations.
- Formula: `F = (C × 9/5) + 32`

### Q2 – Grade Assignment System

- Assigns grades based on student scores.
- Uses `if`, `elif`, and `else` statements.
- Handles invalid scores outside the range 0–100.

### Q3 – List Statistics Calculator

- Calculates mean, maximum, minimum, and count.
- Uses built-in functions such as `sum()`, `max()`, `min()`, and `len()`.
- Handles empty lists.

### Q4 – Palindrome Checker

- Checks whether a string reads the same forward and backward.
- Ignores spaces and capitalization.
- Uses string slicing `[::-1]`.

### Q5 – Item Frequency Counter

- Counts the frequency of each item in a list.
- Uses dictionaries and `for` loops.
- Implements the `dict.get()` method.

### Q6 – Even/Odd Separator

- Separates even and odd numbers from a list.
- Uses the modulo operator `%`.
- Returns two lists as a tuple.

### Q7 – String Case Converter

- Converts strings into uppercase, lowercase, and title case.
- Uses `.upper()`, `.lower()`, and `.title()`.
- Handles invalid conversion types.

### Q8 – BMI Calculator with Category

- Calculates Body Mass Index using weight and height.
- Formula: `BMI = weight / height²`
- Categorizes BMI as Underweight, Normal weight, Overweight, or Obese.

### Q9 – Shopping Cart Total with Discount

- Calculates the subtotal of shopping cart items.
- Applies an optional percentage discount.
- Returns subtotal, discount amount, and final total.

### Q10 – Password Validator

- Validates passwords based on five security rules.
- Checks length, uppercase letters, lowercase letters, digits, and special characters.
- Returns validation status and error messages.
